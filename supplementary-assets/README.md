# Downloads补充素材 / Ressources complémentaires

2026-09-18整理。所有文件为原文件副本，未修改website和线上网站。

- cat-image-references：猫咪正面、侧面、背面与坐姿图，适合建模、贴图或形态参考。
- artwork-sources：中国邮票原图、猫爪、百合视觉。法国邮票原图与现有资产完全相同，清单指向已有文件。
- historical-layout-references：Louis网站早期排版/首屏参考，只作为参考，不应覆盖已确认设计或作为真实履历。
- model-candidates：三个额外猫咪GLB，以及坐姿英短模型和独立贴图。当前线上静坐GLB已在website中，未重复存放。
- animation-source-candidate：105 cat moving中的Walk、Run、Trot三个Blender工程、OBJ及18张贴图。这是另一套备选模型，不是线上猫咪的同一骨架，不能直接替换并期待现有动画正常。
- historical-font-packages：旧版字体原始压缩包，用于保留来源和许可；NewYork原说明明确仅限个人用途，商业使用需要另行许可。当前网站主要字体为Powell和Maranatha，此轮没有替换字体。
