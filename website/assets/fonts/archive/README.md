# Archive typography — production sources, verified 2026-09-15

## Powell Antique Regular

Author: Dieter Steffmann / Typographer Mediengestaltung.

- Author profile and free commercial-use statement: https://www.1001fonts.com/users/steffmann/
- Author distribution: https://www.1001fonts.com/powell-antique-font.html
- Current linked FFC license: https://www.1001fonts.com/licenses/ffc.html
- Verified source archive: https://www.1001fonts.com/download/powell-antique.zip

The Regular TTF in the author's archive is byte-for-byte identical to the existing unmodified PowellAntique.ttf. The current FFC page permits commercial websites and web-app embedding (sections 2 and 6). This portfolio uses the font only to render its interface; it does not offer fonts as a standalone download product.

The archive includes an older five-section EULA without a separate embedding section; its original text is preserved in 1001fonts-powell-antique-eula.txt. Web-use authorization is based on the author's explicit free commercial-use statement and the current embedding terms linked by the font distribution page. Copyright metadata is retained unchanged.

## Maranatha FG Book

Author: Andreas Höfeld / FontGrube AH.
Source: https://www.dafont.com/maranatha-fg-book.font

The accompanying original Maranatha-readme.txt explicitly states SIL Open Font License 1.1. The full license is included in Maranatha-OFL.txt. The original font file is unchanged, including its reserved name Maranatha and embedded copyright information.

## Shared usage

archive-style.css is the single source for typography: Powell Antique headings; Maranatha reading text, navigation and small labels. The LOUIS wordmark keeps its existing font. Fonts are served locally without third-party runtime requests.
